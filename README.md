# BlogDeCafé

BlogDeCafé es una **aplicación web responsiva y moderna** desarrollada para demostrar habilidades en diseño de UI/UX y programación Front-End. El proyecto implementa las mejores prácticas de **HTML5 Semántico y CSS3** para la estructura y el estilo, asegurando una experiencia visual pulida y coherente. El diseño sigue estrictamente la metodología **Mobile First**, garantizando una adaptabilidad perfecta desde dispositivos móviles hasta pantallas de escritorio mediante el uso avanzado de **Flexbox y CSS Grid** para la maquetación.

La interactividad y el dinamismo se lograron utilizando **JavaScript Vanilla (ES6+)**, evitando dependencias de librerías externas para optimizar el rendimiento. Se implementó la API nativa **Intersection Observer** para crear efectos de aparición progresiva (scroll effects) que mejoran la narrativa visual del sitio sin impactar la velocidad de carga. Además, se integraron **animaciones CSS** (transiciones y transformaciones) para proporcionar feedback visual inmediato en elementos interactivos como botones, navegación y tarjetas de contenido.

Como componente funcional destacado, se desarrolló una **calculadora de proporciones en tiempo real**. Esta herramienta utiliza manipulación directa del DOM y lógica aritmética en JavaScript para convertir inputs del usuario en resultados precisos de preparación, demostrando la capacidad de crear utilidades prácticas e interactivas dentro de una interfaz web estática. El proyecto en su conjunto es un ejemplo de código limpio, modular y mantenible, enfocado en la usabilidad y el rendimiento.

## 🛠️ Stack Tecnológico

- **HTML5:** Marcado semántico y accesibilidad.
- **CSS3:** Variables CSS (Custom Properties), Flexbox, Grid, Animaciones (@keyframes, transitions).
- **JavaScript (ES6):** Manipulación del DOM, Event Listeners, Intersection Observer API, Lógica aritmética.
- **Git/GitHub:** Control de versiones y despliegue.
- **Diseño:** Responsive Web Design, Mobile First, UI/UX.
